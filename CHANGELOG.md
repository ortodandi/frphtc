# Changelog

## Versión 1.0.1 (03/06/2025)

### Nuevas características
- Añadida funcionalidad para instalar SuperSU automáticamente
- Añadida funcionalidad para eliminar cuentas de Google sin credenciales
- Mejorado el bypass de FRP para ser más efectivo
- Añadido soporte para mantener el bypass después de reinicios

### Mejoras
- Optimizado el proceso de root para HTC One M9
- Mejorada la interfaz de usuario con información más detallada
- Añadidos mensajes de progreso durante las operaciones

### Correcciones
- Solucionado problema con la detección del estado del bootloader
- Corregido error al acceder a particiones del sistema
- Mejorada la estabilidad general de la aplicación
